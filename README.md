# Amigos Kids Website

A colorful, responsive landing page for a children's YouTube channel, made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, colors, mobile design and animations
- `script.js` — mobile navigation and current year

## Run it on your computer
1. Download and unzip `amigos_kids_website.zip`.
2. Open the extracted folder.
3. Double-click `index.html`. It should open in your browser.
4. For editing, open the folder in a code editor such as Visual Studio Code and edit the files.

You can also use a browser-based editor such as CodePen or Replit by creating an HTML/CSS/JS project and copying each file into the matching panel.

## Customize the YouTube links
In `index.html`, search for `https://www.youtube.com/`. Replace each sample link with the URL of your own channel or video, for example:
`https://www.youtube.com/watch?v=YOUR_VIDEO_ID`

The three video cards currently use sample links and sample artwork; they are not connected to real Amigos Kids videos yet.

## Change the name or text
Open `index.html` and search for `Amigos Kids`, `amigoskids`, or the text you want to change.

## Publish it online
You can publish the folder using GitHub Pages, Netlify, or another static website host. Upload the three files (`index.html`, `style.css`, `script.js`) while keeping them together. No server or database is required for this starter website.

## Notes
- The Google Fonts connection requires internet access; fallback fonts will be used if unavailable.
- The emoji illustrations are placeholders. You can replace them with your own original images.
- If the website is directed at children, have a parent/guardian review the content, privacy choices, and any external links before publishing.
